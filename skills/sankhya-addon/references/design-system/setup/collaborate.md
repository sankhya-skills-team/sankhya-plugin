# Como colaborar

Um design é construido com a colaboração de todos os times que utilizam essa ferramenta, com esse pensamento criamos três fluxos para solicitação de:

## Correção de erro

[Neste link](https://gitlab.sankhya.com.br/dti/design-system/design-system-issues/-/issues/new?issuable_template=error) você será direcionado para a abertura de um erro no nosso repositório de erros do gitlab, aqui devem ser abertas qualquer solicitação de análise de erro em algum componente do design system.

## Nova funcionalidade

[Neste link](https://gitlab.sankhya.com.br/dti/design-system/design-system-issues/-/issues/new?issuable_template=new_feature) você será direcionado para a abertura de uma solicitação de nova funcionalidade no nosso repositório do gitlab, aqui devem ser abertas qualquer solicitação de análise de nova funcionalidade em um componente, ou até mesmo a criação de um novo componente.

## Melhoria na documentação

[Neste link](https://gitlab.sankhya.com.br/dti/design-system/design-system-issues/-/issues/new?issuable_template=improve_docs) você será direcionado para a abertura de uma solicitação de melhoria de documentação no nosso repositório do gitlab, aqui devem ser abertas qualquer solicitação de análise de nova documentação de um componente, ou até mesmo a criação de uma documentação mais detalhada para uma determinada funcionalidade.
