# Visão Geral

## Boas vindas ao Sankhya Design System

Conheça nosso ecossistema de componentes utilizado para proporcionar consistência e padronização do nosso EIP, facilitando o trabalho dos designers e desenvolvedores e proporcionando uma experiência mais simples, consistente e intuitiva para nossos clientes.

Disponibilizamos a documentação de todos os componentes já desenvolvidos e disponíveis para utilização. Nessa documentação você terá acesso a variações dos componentes, assim como, exemplos interativos e de código utilizando o componente. Além disso, é possível acessar um playground, para realizar testes no exemplo do componente. A documentação dos componentes é dividida em duas seções:

### Componentes

Nesse menu você tem acesso a todos os componentes já disponíveis para utilização, além de exemplos da utilização desses. Todos componentes encontrados nessa seção são componentes que não tem nenhum acoplamento com o EIP Sankhya, portanto, esses podem ser utilizados em qualquer aplicação mesmo que fora do EIP.

### Layout

Nesse menu disponibilizamos a documentação das classes CSS disponíveis para a criação de layouts de forma simples, seguindo todas as diretrizes de responsividade e design canônico do design system.

### EIP Componentes

Nesse menu você tem acesso a componentes criados para serem usados em conjunto com o EIP Sankhya, esses componentes têm dependência de algumas estruturas que só o EIP Sankhya disponibiliza, como, por exemplo, o dicionário de dados do sistema e seus provedores de dados. Chamamos esses componentes de blocos de construção, ou building blocks (termo em inglês). Por termos dependência de alguns mecanismos do EIP para esses componentes não temos a demo interativa e nem o playground, porém disponibilizamos exemplos de código e imagens de como o componente se comporta.

### Utilitários

No menu utilitários disponibilizamos a documentação de utilitários que são comuns de serem utilizados no dia a dia de desenvolvimento de uma aplicação, como, por exemplo: formatação de datas e números.
