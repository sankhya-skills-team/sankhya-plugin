# Fundação

A Fundação representa a base estrutural do Design System Sankhya, fornecendo os elementos fundamentais para construção de interfaces consistentes e escaláveis.

## Tokens

Tokens de Design são um tipo de variável que engloba vários elementos de estilo e que podem ser adicionados ao código como um arquivo de dados.

Com um Token é possível fazer várias alterações simultâneas de estilo em um design, sem perda da coesão visual e de experiência do usuário com o produto.

A seguir serão apresentados os tokens criados para tornar acessível um conceito técnico e importante para a construção do Design System da Sankhya.

### O Pacote

O pacote inclui os tokens da fundação estilizados para o acorde:

  * Bordas
  * Cores
  * Espaçamentos
  * Tipografia
  * Tokens

### Guia de Instalação

```bash
npm install @sankhya-acorde/design
```

### Como usar

Importe os estilos do Acorde em seu projeto:

```scss
@import "@sankhya-acorde/design/dist/default/acorde/acorde.css";
```
